# 找货大师

**3.7.0** · 跨电商平台一键找货桌面工具：在多个采购与零售平台上搜索同款或替代货源。

## 功能特性

- 在多个电商 / 采购平台之间切换搜索与比对。
- Electron 桌面应用，平台配置与能力在源码的平台列表中维护。
- 各平台登录会话分开持久化，数据保存在本机用户目录。

## 技术栈

- Electron
- JavaScript

## 从源码运行

源码在 `src/`（`package.json` 与 `src/src`）。本仓库不包含安装包。

```bash
cd src
npm install
npm start
```

产业带相关笔记见仓库根目录 `产业带研究.md`。

# ZhaoHuo Dashi

**3.7.0** · A desktop tool for one-click cross-platform product sourcing: search the same or alternative goods across multiple procurement and retail sites.

- Search and compare goods across multiple e-commerce and procurement platforms.

- Login sessions are persisted per platform in the local user data directory.

- JavaScript
